# 鹅太公外卖采集客户端 0.5.12

当前模式：原有 Google Chrome + 采集扩展 + 本机常驻程序 + 云端设备 API。无需在采集电脑登录中控，也不依赖 Codex 或 VPN。不要使用旧版远程调试步骤或另开的商户登录窗口。

## 首次安装后须核对

- 扩展 0.5.0 已加载到日常使用的 Chrome 用户中，三个平台均已正常登录。
- 独立设备凭据和 HTTPS 证书已安装至当前用户 LocalAppData，不在本目录内。
- Windows 登录后启动已注册，程序串行执行，防止同一平台界面相互冲突。
- 核对独立设备配置中的首次运行日。计划按北京时间美团 01:00、京东 02:00、淘宝闪购 03:00 开始采集前一营业日；各平台内三类报表串行，共享一小时平台冗余。
- 运行前从云端同步当天应采范围与平台 ID；中控修改门店信息后不需要到采集电脑补录。
- 下载后自动 API 上传，核验原件、日期、门店、金额和数据库回读，再写入每日更新核验。

## 日常使用

保持电脑开机、Windows 用户登录且不锁屏，Chrome 可正常访问平台且商户登录有效；接通电源时关闭屏幕和进入睡眠均设为“从不”。当前可见页面采集不能保证在锁屏或熄屏状态运行。无需打开中控或手动点击上传。程序可补开固定平台标签页，请避免同时操作正在采集的平台控件。

管理员进入中控，可在统一的“每日更新”弹窗查看通过、待核验、缺失或失败及对应原因。淘宝闪购结算与该平台其他报表均从 03:00 起按云端计划执行，没有额外的上午时段限制。下载成功不等于门店范围完整；平台 ID 缺失会明确提示。

网络中断时，本地原件和待上传队列保留，恢复后补传旧日期，不重新下载。相同原件与相同范围重复上传不增加入库批次；原件被修改会停止并待核查。

若平台要求重新登录、验证码或拒绝权限，请在原 Chrome 正常处理后恢复；程序不绕过安全验证。首次整夜无人值守和新电脑迁移环境仍需实测。

## 迁移至另一台电脑

安装官方 Node.js 和 Google Chrome，在原 Chrome 加载本目录 windows-client/chrome-extension 扩展，运行“安装Chrome通信组件.cmd”。三个平台在该电脑独立正常登录。

为新电脑单独签发受限采集设备授权与 HTTPS 证书配置，保存到该用户 LocalAppData/EtaigongDeliveryCollector。不要复制服务器 SSH 密钥、浏览器个人资料或另一台电脑的设备令牌。维护电脑若配置了用于绕过 VPN 的物理网卡地址，迁移时不要继承该地址；新设备按实际网络独立配置。

运行“打开并检查采集客户端.cmd”，确认状态为 idle、云端授权已配置；此入口会显示启动失败原因。再运行“设置登录后启动.cmd”。在 Chrome 的 chrome://settings/content/automaticDownloads 允许列表中分别添加 https://waimaie.meituan.com、https://store.jddj.com、https://melody.shop.ele.me，这是新电脑一次性站点配置。域名正式审核完成后再更新设备的 HTTPS 地址与证书。
