# 独立收银报表采集器

此目录保存 2026-10-06 从云端 `/opt/zhongkong-sync-bot/app` 核对取得的采集器源码，使本地、GitHub 与云端的 A/B/C 采集链路有可追溯的代码基线。它是独立 Node 项目，不参与中控后端启动。

- 中控后端：仓库根目录；前端：`frontend/`。
- 采集器：本目录；云端运行位置仍为 `/opt/zhongkong-sync-bot/app`。
- A 综合营业统计、B 品项销售明细、C 门店收支统计的入口在 `bin/`，实现位于 `src/`。
- `npm ci` 只安装依赖。不要在本地直接执行正式采集、补跑、导入或推送入口；这些命令需要独立测试配置和明确任务范围。
- 原云端 README 保存在 `CLOUD_README.md`，其中阶段 0 的进度描述属于历史记录，不代表当前源码功能状态。
- 登录态、凭证、任务状态、下载文件和日志均不入库，也不从生产同步到本地。

本次同步仅归档采集器源码，不改变其生产计划、配置与运行行为。
