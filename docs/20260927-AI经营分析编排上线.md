# AI 经营分析编排（2026-09-27）

## 功能边界

- 中控入口：数据分析 → AI 经营分析，路由 `/analysis/agents`。
- 固定路线：队长定口径 → 渠道专员 → 菜品专员 → 账本专员 → 队长综合。
- 仅从已导入的 `business_revenue_records`、`business_revenue_compositions`、`pos_product_sale_details`、`bookkeeping_entries` 及账本导入链接读取聚合数据。结果存入独立 `analysis_agent_runs` / `analysis_agent_steps` 审计表，不修改原始经营数据。
- 用户可选择规则模式或已配置模型辅助解读、模型配置与思考深度。模型只接收所选门店和日期范围内的聚合事实，前端须二次确认；展示结论摘要，不展示或保存模型内部思维链。
- 模型断线时保留规则计算并显示警告。执行路线、取数表、覆盖天数、阶段结果和建议均可在任务详情追溯。
- 不提供数据导入、报表导出、改价或企微群推送能力。建议须由人审批实施。

## 口径约束

- 收银店内实收与嵌入的团购/支付分类不能相加。
- 第三方平台到账独立列示，不与收银系统实收相加；无平台实收数据时不计算真实平台占比。
- 品项收入与综合营业统计是同一经营活动的不同表，不相加。
- 会员充值不作为当期营业收入；账本净额不等于利润。
- 已知账本源表缺少历史版本，不能判定旧日数据是否被追改。
