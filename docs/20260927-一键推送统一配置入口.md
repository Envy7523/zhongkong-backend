# 一键推送统一配置入口（2026-09-27）

## 本次整理

- 左侧「一键推送」现在是统一入口，不再只展示团购日报。页签：总览、报表同步内容与时间、收银日报内容、发送机器人、日报发送时间、团购日报推送。
- 报表同步页沿用 `report_sync_plans` / `schedule_config.sync_*`：当前收银系统 A/B/C 可以分别启停、设置时间；这只控制采集、校验和导入，不触发企微消息。
- 收银日报内容页沿用已审批的图片预览、门店范围和路由审批。其他报表虽可入库，不会自行混入收银日报。
- 发送机器人页沿用 `wecom_message_routes`，按消息类型选择企微机器人。机器人及 Webhook 凭据仍仅在「企业设置 → 机器人设置」登记；此页不复制凭据。更换绑定由后端自动关闭路由，必须重新预览和审批。
- 日报发送时间页沿用 `schedule_config.report_*`，中控单独生成并发送；和采集时间完全独立。团购原有人工预览与推送功能保留在单独页签。
- 配置页签只对 `enterprise-settings.manage` 岗位显示；仅有 `pipeline.manage` 的岗位保留团购日报推送界面，不获得计划或机器人配置权限。
