# 日报机器人路由收敛（本地待发布）

## 页面归属

| 地址 | 职责 |
| --- | --- |
| `/enterprise-settings/robot` | 登记、修改企业微信群机器人及 Webhook；不分配日报目标 |
| `/data-import/pos/automation/schedule` | 收银报表采集和入库计划；不控制群消息 |
| `/pipeline/pos-daily` | 收银日报目标、预览、测试发送和路由启用 |
| `/pipeline/pos-daily/schedule` | 收银日报每天自动发送的时间、开关及运行记录 |
| `/pipeline/group-buy-daily` | 团购日报目标、预览、路由启用和人工推送 |

旧地址 `/pipeline`、`/enterprise-settings/schedule`、`/data-import/pos/automation/daily-report` 分别重定向到团购日报、收银自动发送、收银预览与目标页面。原来的推送中心多页签和企业设置中的重复目标分配已移除。

## 启用流程

1. 在企业设置登记机器人。
2. 在对应日报页面选择并保存发送目标。更换目标后，后端自动关闭该路由。
3. 生成只读预览，确认内容、数据口径和目标群，然后在同页启用路由。界面使用“待确认启用”，不存在独立审核队列。
4. 收银日报的自动发送计划仍须另行开启；团购日报仍须人工确认推送。保存目标和启用路由不会立即发群消息。

## 收银日报门店范围

收银日报不再按门店主档状态要求逐店覆盖，也不再维护人工排除清单。预览、测试发送、自动发送共用同一规则：当天有非零收银金额或订单量的门店纳入；全零或没有记录的门店不展示；有部分数值但缺关键字段的门店仍纳入校验，校验失败时阻止发送。已保存的旧排除数据留在数据库中供历史追溯，但不再参与计算，也没有修改入口。

高位、中位、低位在少于 9 家门店有数据时自动缩减，不因临时歇业而阻止整份日报。
