## 当前状态

本地已实现并验证。云端尚未部署；2026-10-07 检查时 SSH 连接被服务器关闭，云端 providers 接口的 openid.enabled=false。

## 使用方式

1. 员工点击「微信登录」，填写真实姓名、可选联系方式并提交申请。
2. 将小程序显示的申请编号告知管理员；姓名和联系方式均为员工自行填写，审核前须核实本人。
3. 管理员在 PC「人员管理 → 微信登录绑定审核」核实编号、选择后台人员并批准。
4. 员工再次点击微信登录，系统映射至所选 users.id，读取该人员当前岗位权限与门店绑定。
5. 管理员可拒绝申请或解除绑定；解除后已有微信会话立即失效，重新批准也不会恢复旧令牌。

每个后台人员最多保留一个有效微信绑定。账号密码登录保留作应急入口。不读取微信昵称、头像或通讯录，也不根据姓名自动授权。OpenID 由后端使用 wx.login 的 code 向微信服务器验证，不接受客户端提供的 OpenID。
