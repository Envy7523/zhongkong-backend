# 集团督导兼任店长与账号多岗位

- 员工与登录账号是两套岗位关系。员工主归属保留集团、主岗位为门店督导，并登记兼任店长岗位；在人事调整中指定督导兼任门店。
- 只有集团主岗位包含“督导”、并有店长任职的员工可以启用此特例。其他岗位默认行为不变。
- 督导的应出勤、排班、打卡核算及调休额度按兼任门店规则走，不进入办公室统一日历名单；员工档案和工资归属仍为集团。
- 集团工资表正常发薪；制作兼任门店工资表时纳入姓名，明确标注集团发薪、门店应发0，展示行不能编辑薪酬、奖励、代扣或计入门店工资；后台也强制归零。展示行不暴露银行卡和身份证信息给店长。
- 历史工资表保留原快照，不追溯重写已提交/已审核工资。排班库存沿用既有启用日期和有效期。
- 系统预设账号岗位“门店督导（兼任店长）”，含本店员工编辑、工资查看及制作权限。用户自行分配账号岗位，可以同时选择店长或其他岗位。
- 账号可选择1至10个岗位，权限取并集；每次请求从数据库读取合并权限，撤销即时生效。没有集团人事或审核权限的店长/督导账号只能管理绑定门店；人事权限合并后沿用人事的集团范围。账号岗位本身不自动改员工归属或薪资。
- 旧单岗位账号自动迁移为一个岗位；保留旧position_id兼容字段。谢开铭的账号权限由管理员自行选择，不自动追加权限。

旧草稿/已保存/退回表读取时按当前督导兼任关系显示零工资；读取不改原存储快照，保存或重新生成时才落库。已提交/已审核表不追溯重算。个人考勤日历也使用门店规则，删除账号时一并清理账号岗位关系。
