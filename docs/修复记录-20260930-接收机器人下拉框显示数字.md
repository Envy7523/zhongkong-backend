# 修复记录：接收机器人下拉框只显示「2」而不是机器人名（2026-09-30）

## 一、现象

企业设置 → 推送中心 → 收银系统每日高低位数据（`PosDailySettings.vue`）页面：
「全店汇总接收机器人 · 发送机器人」下拉框里显示的是一个数字 **2**，而不是「日报助手」。
连带现象：**「向当前群发送一条测试日报」「启用日报路由」按钮始终不可用**。

## 二、根因：后端投影漏字段，前端过滤恒为空

`lib/wecom-routing.js` 的 `publicBot` 只回传 5 个字段，**没有 `audience`/`store_id`**：

```js
// 修复前
const publicBot = row => ({ id, name, enabled, configured, updated_at });
// GET / 的 SELECT 也没取 audience/store_id 列
```

而前端按 `audience` 取值：

| 位置 | 代码 | 后果 |
|---|---|---|
| `PosDailySettings.vue:43` | `bots.filter(bot => bot.audience === 'management' && bot.enabled && bot.configured)` | 选项列表**恒为空** |
| `PosDailySettings.vue:42` | `boundBot` 同样要求 `audience === 'management'` | 恒为 `null` → 测试发送/启用按钮永久禁用 |
| `PosStoreBotOverview.vue:39` | `bots.filter(bot => bot.audience === 'store' && bot.store_id)` | 门店机器人列表恒为空 |

**为什么显示 "2"**：`el-select` 的选中值来自路由绑定 `bot_id = 2`，但 `el-option`
列表为空 → 找不到匹配项 → Element Plus 退化为直接渲染原始值，于是显示 `2`。

### 证据（修复前实测）

```
库内数据：  {"id":2,"name":"日报助手","enabled":1,"audience":"management","store_id":null}
路由绑定：  pos_daily -> {"bot_id":2,"bot_name":"日报助手","enabled":false,"revision":4}
接口返回：  bots[0] keys = id,name,enabled,configured,updated_at      ← 没有 audience
```

数据层与路由层都是正确的，**问题只在读取投影**。

## 三、改动（`lib/wecom-routing.js`）

1. `publicBot` 增加 `audience`（缺省 `'management'`）、`store_id`，关联门店时补 `store_name`
2. `GET /` 的 SELECT 带出 `audience,store_id` 并 `LEFT JOIN stores` 取 `store_name`；
   同时返回 `stores` 清单（门店群机器人分配需要，按 `id DESC` 稳定排序）
3. `POST /bots`、`PUT /bots/:id` 支持 `audience`/`store_id` 写入；门店不存在、门店已被占用、
   门店重复绑定分别返回 400/409；改绑定或启停会关闭相关消息路由（与凭证变更同一处理）
4. `PUT /routes/:code` 与 `POST /routes/:code/activation` 拒绝把项目日报分配给**门店群机器人**

## 四、附带修复：测试脚本此前完全跑不起来

`scripts/test-wecom-routing.js` 有两个问题：

| 问题 | 说明 | 处理 |
|---|---|---|
| 缺 `pos_daily_scope_exclusions` 表 | `GET /` 会查这张表，缺表直接 500（`no such table`），脚本第一步就崩 | 补建该表 |
| 两处过时断言 | 断言 `PUT /pos-daily/exclusions` 返回 404、`GET` 不含 `exclusions`——而实现早已具备完整排除名单接口（含校验与零写入保证） | 改为正向断言 + 非法输入（门店不存在）必须 400 且零写入 |

并新增断言覆盖本次修复：`audience` 必须为字符串、门店群机器人带 `store_id`/`store_name`、
管理群机器人 `store_id` 必须为 `null`、`stores` 清单长度。
