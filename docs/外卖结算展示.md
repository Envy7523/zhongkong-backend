# 外卖结算展示

美团外卖门店视角沿用横向金额栏：营业额 − 支出 = 实际到账 − 第三方成本 − 菜品成本 = 实际到手。支出明细通过悬停查看，不再铺开结算表格和重复解释。

顶部营业额、营业收入继续取平台营业日报。结算链有账单时按已结算且有营业日报的店日计算营业额和订单应收，非订单扣款、返款保留账单的真实交易类型；部分店日未结算不作为费用，不阻止已上传部分计算。到账为零、负数都保留。仅有营业日报而未上传结算时展示营业收入，不冒充最终到账。第三方成本、菜品成本继续沿用当前筛选范围的已导入成本。

收银机有数据、平台未上传，以及缺结算或缺营业日报的店日，在金额栏下方以可展开的待补报表提示呈现。提示独立于汇总，即使平台视角排除了未上传记录，也仍列出待补店日。营业日报尚未导入的订单结算不反推营业额或优惠，继续保留在原结算总额及待补提示中。
