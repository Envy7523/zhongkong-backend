## 本项目建议

采用 Vben / shadcn 的清晰层级与克制视觉作为参考，保留现有 Element Plus 业务组件和表单引擎，通过统一设计变量与页面布局逐页改造。Pure Admin 可作为接近现有技术栈的组件实现参考。不建议因视觉需求直接整仓替换已有后台：已有权限、门店范围、业务接口和表单数据模型需要继续兼容。

改造顺序：先用门店日常任务模块做样板，覆盖表单列表、三栏表单设计器、任务进度和审核详情；本地验收后再统一导航和其他业务页面。先统一字体、色彩、间距、控件高度、圆角、状态标识和空白状态；缩减过大的卡片和重复说明，提高表格和筛选区域的信息密度。表单编辑区有明确画布与属性区，属性面板正确换行、独立滚动，避免裁切和横向溢出。

组件库、后台模板和拖拽表单设计器是不同层次。上述项目不能自动替代目前表单引擎的题型、说明图片、共同执行和审核功能。复用实际代码时保留 MIT 许可证和版权声明；付费扩展、素材及附属产品需分别核对。

本次仅调研与记录，没有安装新的 UI 依赖、替换页面、修改小程序或部署云端。
