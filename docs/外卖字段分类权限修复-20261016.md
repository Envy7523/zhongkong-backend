# 外卖字段分类权限修复

用户反馈运营专员勾选“数据分析”后仍不能编辑外卖字段分类，已明确其勾选项为“数据分析”。

根因：该页面位于数据分析/外卖视角，但前端菜单、路由和服务端旧地址 `/api/enterprise-settings/delivery-fee-rules` 仍要求 `enterprise-settings.manage`。云端运营专员已持有 `analysis.view`，无需修改其岗位配置。

修复：菜单、路由、分类GET/PUT接口统一使用 `analysis.view`。为旧接口地址增加精确前缀规则，其他企业设置仍使用原企业设置权限；原有管理员、登录检查、分端与逐岗位门店范围检查保留。

验证：

- `tools/delivery-fee-permissions-smoke.js` 在内存模拟库运行实际权限中间件与分类路由，验证仅数据分析权限可读取/保存；未授权、匿名、仅小程序端授权、门店范围受限账号被拒绝；企业设置/人员/岗位/记账标签及相似前缀接口不能借此访问；前端菜单与接口权限一致。
- 浏览器加载真实路由和字段分类组件，模拟仅持有 `analysis.view` 的运营账号进入页面、修改一项示例分类并成功保存。证据 `_tmp/delivery-permission-fix-20261016/operator-save.png`。
- 分端资料权限、逐岗位范围、人员管理检查及外卖分类/营收18项测试通过；Web构建、发布检查和隐私自动检查通过。

仅修复权限映射，不改费用分类规则、金额计算或已保存岗位/人员授权。小程序代码和实际收集字段、SDK、用途没有变化；微信后台及真机两项人工核验本轮未重做，不登记为已通过。发布后版本与验证结果补充于下文。
