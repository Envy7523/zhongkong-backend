# 美团外卖营业收入与结算覆盖

营业收入卡片取营业日报的 `income_amount`，不替换成结算到账。原来的“客户优惠”差额卡改称“补贴及支出”，避免把平台费用也当作客户优惠。

结算面板按同门店、同日期检查原始 `meituan_delivery_bills` 的订单结算记录。已有原始流水合计单独显示为“已导入结算到账”；真实零到账和负到账保留，不回退成营业日报收入。有营业但缺订单结算的店日列出待核营业收入；有订单结算但缺营业日报也提示缺失。资料不足时不展示整段支出恒等式和实际到手，不能将未覆盖收入解释为平台扣款。

资料齐全时，营业额与结算订单应收之间的差额称为“订单内优惠及扣费（差额）”，其余费用按原始交易类型展示，扣款为正、净入账为负。推广充值、推广消耗和退款保留原名；不再生成美团外卖“其他结算调整”。该拆分解释资金到账，不把充值认定为当日广告实际消耗。

只调整读取和展示，不补造结算数据。缺失结算需重新取得对应日期的真实原件并通过既有导入功能补齐。美团门店、品牌、平台视角复用相同日期和门店范围；其他外卖平台保持既有逻辑。
