# 企业数据工作台主题

采用深石墨导航、浅灰工作区、白色表格与钴蓝操作色。

## 入口与边界

- `src/styles/enterprise.css`：基础值、语义变量与组件规范，入口在 `src/main.js`。
- `App.vue` 的 `enterprise-theme` 类限定已登录工作区；登录页保留独立品牌构图。
- 分析页面环比保留原比较逻辑，不再绑定 `compare-mode` 的深色外观；图表使用浅色配色。
- 不修改接口、数据库、平台取数、财务公式、路由和缓存行为。

## 规范

- 页面背景 `--surface-page`，卡片背景 `--surface-card`，强调色 `--action-primary`。
- 标题 24px，正文以 13–14px 为主，辅助说明 12px；金额使用等宽数字。
- 卡片圆角 8px，控件圆角 6px；边框分层，不使用大面积渐变和悬浮阴影。
- 表格保留收入、支出、会员储值及异常行的原有语义颜色。
- 筛选区允许换行：日期框 184px，日期范围 300px，平台门店框 240px。鼠标悬停不改变几何尺寸。
- 卡片和内容分栏按工作区容器宽度响应，避免侧栏状态导致挤压；窄窗口的表格由自身滚动，不强制撑大页面。
- 后续新组件应复用变量。已有页面的样式覆盖集中在主题文件，不再逐页增加渐变和阴影。

## 验证

运行 `npm run build`（frontend 目录）。原有大包体积警告不属于主题变更。

`scripts/ui-theme-smoke.mjs` 是无需额外依赖的独立浏览器检查：

1. 前端运行 `npm run preview -- --host 127.0.0.1 --port 4173`。
2. 使用独立临时用户目录启动无界面 Chrome，开启调试端口 9335。
3. 仓库根目录运行 `node scripts/ui-theme-smoke.mjs`。

测试使用拦截的模拟接口数据，不访问真实业务数据，也不验证财务计算。
检查 1920、1366、1024、768 宽度的平台页面溢出、主题应用、日期框宽度与悬停稳定性，以及月看板筛选区和环比入口外观。
截图默认输出至系统临时目录 `etaigong-theme-smoke`。
此检查不代表全部业务路由的端到端回归；新增页面仍需检查实际数据、长名称、加载与空状态。
